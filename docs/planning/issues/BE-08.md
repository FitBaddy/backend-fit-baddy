## Что сделать
Единый `TelemetryDTO`, симулятор, поток WS.

## Детали / спецификация
- `backend-fit-baddy/app/modules/devices/models.py`: `devices` (device_id UK, device_token, kind), `telemetry_points` (steps, heart_rate, calories, timestamp, source).
- `POST /api/v1/devices/register` → `{device_id, device_token, user_id, kind, status}`.
- `POST /telemetry/simulate` (тело опционально) → 201 `source=simulator`; `GET /telemetry/latest` (404 без точек), `GET /telemetry/history?limit=`.
- `WS /api/v1/telemetry/ws?token=` или первым сообщением `{"token"}`; неверный токен → close 4401.
