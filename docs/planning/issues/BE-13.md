## Что сделать
Точка входа для публикатора узла Pi.

## Детали / спецификация
- `POST /api/v1/telemetry/ingest`, заголовок `X-Device-Token`; тело — `TelemetryDTO` без `user_id`.
- 401 — нет/неверный токен; 403 — `device_id` не совпадает с токеном; 422 — отрицательные значения, `heart_rate` вне 30–230.
- `user_id` берётся из `devices`.
